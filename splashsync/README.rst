=====================
Splash Sync Connector
=====================

Synchronize Odoo with any application through `Splash Sync <https://www.splashsync.com>`_:
customers, addresses, products, orders and invoices.

Configuration
=============

Settings > Splash Sync: enter the server identifier and encryption key given by Splash for each
company, and the Odoo user used for changes made by Splash.
